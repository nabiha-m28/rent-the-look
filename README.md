# Rent the Look

- Built a full-stack web application, Rent the Look, that converts retail product URLs into rental alternatives across platforms, featuring retail-versus-rental price comparisons, Pinterest-style boards for saving curated rental listings, and Supabase-backed user authentication
- Engineered a data extraction pipeline using Scraper API to extract metadata, handle anti-bot protections, and inconsistent website schemas
- Developed cross-platform search and ranking algorithms with keyword scoring, query simplification, and scoring-based result ranking to improve matching accuracy for fashion products


## Features

- Paste any product link and find it (or the closest match) across major rental platforms
- Retail vs. rental price comparisons with savings displayed
- Filter results by size
- Save listings to custom boards with Supabase-backed user accounts
